FASE 03 // ATTACCO BRUTE FORCE

Forzare il Cifrario con Python

A mano ci vogliono minuti per decifrare una frase intera senza conoscere la chiave. Con un semplice ciclo for in Python, il computer prova tutte le 25 chiavi in meno di un millesimo di secondo!

🔒 Messaggio Intercettato (Cifrato) Chiave sconosciuta
"AOL VUSF DHF AV KV NYLHA DVYR PZ AV SVCL DOHA FVB KV. ZAHF OBUNYF, ZAHF MVVSPZO."

Ogni lettera dell'alfabeto è stata spostata in avanti sempre dello stesso numero di posizioni, mentre spazi e punteggiatura sono rimasti invariati.

🐍 brute_force_cesare.py 
alfabeto = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
frase_cifrata = "AOL VUSF DHF AV KV NYLHA DVYR PZ AV SVCL DOHA FVB KV. ZAHF OBUNYF, ZAHF MVVSPZO."

# Ciclo for per provare tutte le 25 chiavi possibili (Brute Force)
for chiave in range(1, 26):
    frase_decifrata = ""

    # Scorro ogni singolo carattere della frase cifrata
    for lettera in frase_cifrata:
        if lettera in alfabeto:
            posizione = alfabeto.index(lettera)
            nuova_pos = (posizione - chiave) % 26
            frase_decifrata += alfabeto[nuova_pos]
        else:
            frase_decifrata += lettera

    print(f"Chiave -{chiave:02d}: {frase_decifrata}")
2 cicli for annidati: 25 chiavi × 81 caratteri = 2.025 operazioni.
